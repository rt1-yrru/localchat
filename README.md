### Direct Compatibility Breakdown

* **API Endpoints**: The frontend queries `GET /api/tags`, `POST /api/generate`, and connects to `WS /ws`, matching the backends exactly.


* **Stream Payload Mapping**: The frontend listens for NDJSON chunks with `"response"`, `"done"`, `"event": "request_started"`, `"prompt_eval_count"`, and `"eval_count"`, which are the exact JSON signatures emitted by the backends.


* **Stop Requests**: The frontend supports interrupting text generation mid-stream using WebSocket stop events (`{"event": "stop", "req_id": "..."}`).

# README: Minimal Web Client (`index.html`)

A lightweight, zero-build single-file web interface for the Gemini Adapters, featuring real-time Markdown rendering, KaTeX math formatting, syntax highlighting, and dual-mode streaming (WebSocket and HTTP Streaming).

**Features**

* **Direct Gemini Backend Integration**: Auto-fetches model lists and vendor status.


* **Dual Connection Engine**: Switch between WebSocket and HTTP Stream (NDJSON) protocols seamlessly.


* **Rich Text Support**: Markdown parsing via `marked.js`, math equations via `KaTeX`, and code block syntax highlighting via `highlight.js`.
* **Execution Control**: Stop ongoing generations instantly with live token count feedback.



---

**Setup & Usage**

**1. Configure Server Port**

Open `index.html` in an editor, locate the `API_BASE` constant near line 192, and set it to your running service port:

```javascript
// For Python FastAPI Service (gemini_service.py)
const API_BASE = 'http://127.0.0.1:8081';

// OR for Bun Service (gemini_main.ts)
// const API_BASE = 'http://127.0.0.1:8082';

```

**2. Open in Browser**

No compilation or web server setup is required. Open `index.html` directly in a modern web browser:

```bash
# On Linux
xdg-open index.html

# On macOS
open index.html

```

Or serve it using Python's static file server:

```bash
python3 -m http.server 3000

```

Navigate to `http://localhost:3000` in your web browser.

---

**Interface Controls**

* **Sidebar**:
* **Model**: Dynamically populates available Gemini models provided by `GET /api/tags`.


* **Connection**: Toggle between **WebSocket** (lower latency, bidirectional) and **HTTP Stream** (NDJSON standard).


* **Temperature**: Adjust model creativity ($0.0$ to $1.0$).


* **Chat Window**:
* **Send Message**: `Enter` (or click Send arrow).
* **New Line**: `Shift + Enter`.
* **Cancel Generation**: Click the Red Stop Button during generation.



# README: Minimal Local Chat Frontend (`a_1.html`)

A lightweight, single-file HTML/JS web application providing an interface for local AI services. Built with vanilla JavaScript, CSS variables for dark-mode styling, **KaTeX** for mathematical typesetting, and **Marked.js** with **Highlight.js** for code formatting.

---

## 🌟 Features

* **Dual-Streaming Modes**: Supports both real-time **WebSocket** frames and **HTTP NDJSON** streams.
* **Full Markdown & Math Formatting**: Integrates `marked.min.js`, `highlight.js` (GitHub Dark Dimmed theme), and `katex.min.js` to render code blocks, tables, and LaTeX equations.
* **Stop Generation Support**: Includes live cancellation, signaling backend services to cease output mid-stream.
* **Dynamic Vendor & Model Discovery**: Queries the backend `/api/tags` endpoint to automatically select models and present vendor branding.
* **Responsive Control Panel**: Allows quick switching between model types, connection protocols, and temperature parameters (`0.0` to `1.0`).

---

## 🔌 Backend Compatibility Statement

This single-file frontend directly interfaces with standard **Ollama API endpoints** running on port `9090` (or `8082`, adjustable via `API_BASE`). It is fully compatible with:

1. **OpenRouter Service Adapters**:
* Works with both Python (`open_router_service.py`) and Bun (`openrouter_main.ts`) adapters.
* Maps incoming OpenRouter completion deltas into NDJSON/WebSocket tokens.
* Handles `/api/tags` filtering to populate free tier LLMs.


2. **Gemini Service Adapters**:
* Compatible with Gemini proxy adapters that normalize Google AI Studio / Vertex AI streams into the standard Ollama NDJSON format (`{"response": "...", "done": false}`).
* Fully supports mathematical outputs generated by Gemini using LaTeX delimiters (`$$...$$` or `$ ... $`).

## 📡 Expected API Endpoints

To connect custom backends (such as Gemini or OpenRouter adapters), ensure your service implements the following contracts:

| Endpoint | Method | Description |
| --- | --- | --- |
| `/api/tags` | `GET` | Returns JSON containing `{ "vendor": "OpenRouter", "models": [{"name": "model-id"}] }` |
| `/api/generate` | `POST` | Accepts `{ "model": "...", "prompt": "...", "temperature": 0.7 }` and returns an `application/x-ndjson` stream. |
| `/ws` | `WebSocket` | Handles bi-directional JSON messages for `"prompt"` sending and receiving streaming chunks. |
| `/api/stop` | `POST` | Accepts `{ "req_id": "..." }` to interrupt execution. |
